# 10 taglines — Oscar rules, one line back

Playbook #29: at 700 submissions the tagline is load-bearing. Test for each —
*"in a list of 700, would I click this?"* Ranked by my read; the ranking is not the ruling.

| # | Tagline | What it leads with |
|---|---|---|
| **1** | **Your agents already told you what to build next. Nobody was listening.** | the insight — accuses the reader's stack, not the product |
| **2** | **A catalog entry for data that doesn't exist yet.** | the category, in one object. Name = idea |
| **3** | **Write SQL against a table that doesn't exist. Get told when it runs.** | the moonshot, concrete and slightly impossible-sounding |
| 4 | Demand-side metadata. | the category label alone. Strong in a track list, weak cold |
| 5 | Three agents asked for the same missing table. So it got built. | the whole pipeline in one sentence |
| 6 | Failed searches are a roadmap. | the reframe. Short, quotable, slightly abstract |
| 7 | Every miss is a vote. | tightest. Maybe too tight — "miss" needs context |
| 8 | The catalog for things that aren't there. | clean paradox, reads as clever more than useful |
| 9 | Agents ask. The catalog answers by building it. | mechanism-forward, a touch flat |
| 10 | Ghost → solid. | the wordmark, not a tagline. Good as a section header |

## My recommendation

**#1 as the Devpost headline** — it is the only one that makes the reader feel a loss
they already have. **#2 as the subtitle**, because it is the category and it is the
name. **#3 in the video's last ten seconds**, where the impossible-sounding claim lands
right after the proof.

Banned per the kill list, so none of these say: seamlessly · unlock · supercharge ·
effortless · empower.
