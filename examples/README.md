# Sample outputs

Place judge-facing artifacts here after the build starts (generated dbt models, DAG snippets, reports, screenshots of lineage write-back, etc.).

Empty until a concept is locked and implementation produces outputs.

## Models an agent wrote

The `.sql` files beside this README were generated by the Nullspace builder agent
from the requesters' own registered queries, then opened as pull requests against
[`Morkeeth/nullspace-dbt`](https://github.com/Morkeeth/nullspace-dbt/pulls?q=is%3Apr)
and merged by a human. Each one names its generation tier and the grain it chose
in the header comment, so you can judge the output without running anything.
