# GPT-5.x (`gpt-5.6-sol-medium`)

NAME — Scar Tissue
CATEGORY IT CREATES — Graph-bound failure memory for agents
THE 3-MINUTE AHA — One agent fails a join; a fresh agent receives the identical task and succeeds because that failure became asset-specific context.
WHAT IT WRITES BACK to the graph — Failed assumption, evidence, affected entities, owner, and expiry.
SPONSOR-NATIVE PROOF — Without canonical entities and lineage, the lesson cannot reach the next agent at the right asset.
WHY IT'S 2 DAYS not 2 weeks — Read → diagnose → write; two agent runs, seeded datapack, exported event replay.

NAME — Airgap Relay
CATEGORY IT CREATES — Air-gapped metadata delegation
THE 3-MINUTE AHA — A cloud coding agent, never connected to private DataHub, returns working SQL; the local relay validates its capsule and commits the receipt.
WHAT IT WRITES BACK to the graph — Used-entity lineage, output lineage, graph hash, and validation result.
SPONSOR-NATIVE PROOF — DataHub assembles the capsule from schemas, lineage, ownership, and governance, then checks staleness on return.
WHY IT'S 2 DAYS not 2 weeks — Assemble → delegate → validate using JSON artifacts; the live URL replays them while Docker Compose runs the full loop.

NAME — Context Diet
CATEGORY IT CREATES — Graph-fed context compilation
THE 3-MINUTE AHA — The same task drops from 14,000 to 1,200 context tokens and flips from selecting the wrong field to producing a passing query.
WHAT IT WRITES BACK to the graph — Entity usefulness scores, rejected-context reasons, task fingerprint, and compact summary.
SPONSOR-NATIVE PROOF — Without graph traversal and canonical cross-stack identities, subtraction becomes unsafe keyword trimming.
WHY IT'S 2 DAYS not 2 weeks — Compile → execute → score over a seeded graph; token counts and SQL execution are real.

NAME — Flight Recorder
CATEGORY IT CREATES — Decision lineage for data agents
THE 3-MINUTE AHA — After a metadata edit, replay highlights the exact stale catalog fact that caused yesterday’s generated SQL to fail.
WHAT IT WRITES BACK to the graph — Agent-to-entity context hashes, output links, failure evidence, and supersession receipt.
SPONSOR-NATIVE PROOF — Without DataHub, no canonical before/current graph exists to explain which context changed.
WHY IT'S 2 DAYS not 2 weeks — Capture → mutate → replay-and-repair; seeded metadata and custom properties suffice.

NAME — Branchline
CATEGORY IT CREATES — Metadata branches for coding agents
THE 3-MINUTE AHA — A rename proposal becomes a tested dbt patch; the graph switches from proposed red to merged green with lineage preserved.
WHAT IT WRITES BACK to the graph — Proposal status, executable evidence, approved schema, and resulting lineage.
SPONSOR-NATIVE PROOF — DataHub is both the base diff and merge target; remove it and the proposal loses its cross-stack meaning.
WHY IT'S 2 DAYS not 2 weeks — Propose → test → merge one migration; tags and custom properties model the branch.

RANKING — Monday-morning memorability
1. Scar Tissue
2. Airgap Relay
3. Context Diet
4. Flight Recorder
5. Branchline

Scar Tissue wins because its demo has a clean before-and-after: one agent bleeds, the next inherits immunity. It turns DataHub from passive context into institutional memory that compounds across agents. The name, mechanism, and sponsor-native writeback collapse into one Monday-morning story.

MOST LIKELY BUILT BY 20 OTHER TEAMS — Branchline; metadata-aware migration generation is the obvious track-shaped idea.
